# Контракты UI и текстов: ревизия2

Статус: спецификация, без новой проверки рендера. Углубляет R01/R03/R05/R06/R12/R14/R17/R19. Применять новые четыре навыка по назначению.

## Карточка метрики

- Вход: определение, число или null, единица, период/выборка, состояние данных, reason, coverage с основанием, дата наблюдения, допустимый переход.
- Состояние запроса отдельно: initial loading, refresh, success, error. Ошибка запроса не затирает подтверждённое прошлое значение без объяснения; смена выборки не подписывает старое число новым контекстом.
- Ноль обрабатывается явно. Partial используется согласно контракту конкретной метрики. Названия enum из другого API не интерпретируются универсально.
- Значение, единица и существенное ограничение читаются без hover. Дополнительная методика — в раскрытии.
- Нельзя делать всю карточку кнопкой, если внутри независимый фильтр/кнопка создаёт вложенные интерактивные элементы. Для actionable карточки проверяются доступное имя и реальный destination; неactionable карточка не маскируется под ссылку.

## Источник и сообщения

| Факт | Видимый смысл | Действие |
|---|---|---|
| Подтверждённый ноль | 0 ₽ /0визитов; отсутствие продаж только при подтверждённом покрытии | Детали либо обычное чтение |
| Источника остатков нет | Данных об остатках пока нет | Подключить/проверить источник только доступной роли |
| Нет установленной причины | Показатель пока недоступен | Предусмотренная детализация; не выдумывать сбой источника |
| Известна часть | По подтверждённой части; Учтено {доля} {операций/выручки/позиций/клубов} | Те же строки и показанное основание |
| Старое наблюдение | Остатки на {дата}. Данные устарели | Дата inventory, не общего sync |
| Сбой при наличии прошлого значения | Не удалось обновить данные. Показаны значения на {дата} | Повторить чтение |
| Задача обновления только принята | Обновление запланировано | Статус задачи, без обещания нового факта |
| Прошлая база0 | Абсолютное изменение; процент не рассчитывается, раньше0 | Сравниваемые значения |
| Действие недоступно роли | Понятное ограничение; при действующем процессе — обращение к администратору | Не показывать закрытую ссылку/чужие детали |

Примеры — шаблоны, а не неподтверждённые runtime причины. Если нет точного покрытия, не писать выдуманный процент. «Без продаж» не переименовывается в «без движения»; «товарные позиции в клубах» не становятся уникальными товарами сети. Отсутствие цены не скрывает подтверждённый количественный риск.

## Фильтр клубов и периода

- Только разрешённые варианты; выбранное множество и применённое множество различаются до подтверждения.
- Общий DashboardFilters расширяется совместимо либо используется подходящий существующий аналог. Сохранить потребителей ассортимента.
- URL — восстанавливаемый контекст, а не декоративная строка. Учесть Back/Forward, внешнее изменение props/URL и reload.
- При быстрых A→B последний ответ A не меняет B; выбранные фильтры, заголовок, данные и детализация относятся к одному принятому контексту.
- «Все доступные клубы» не означает автоматически весь tenant. Не расширять роль.
- Фильтр с отсутствующим на destination измерением требует рабочего адаптера или честного ограничения, не скрытого отбрасывания.

## Таблица, график и детали

- Сортировка меняет фактический порядок. Неизвестные/несопоставимые строки не получают искусственный0. Правило их размещения явно фиксируется.
- Коэффициенты сети пересчитываются по основаниям; среднее процентов запрещено без специального бизнес-определения.
- График имеет единицы, подписи и доступный эквивалент. Пропуск ряда не рисуетсянулём, не сшивается в подтверждённую непрерывную линию.
- Детали показывают ту же выборку, основание агрегирования и результат. Для отношения — числитель/знаменатель; для агрегата по дням/клубам — явное указание этого уровня.
- Модальное окно: начальный focus, trap по паттерну, Escape, возврат инициатору. Поповер не получает роль modal без соответствующего поведения.

## Тема и читаемость

Использовать текущие --background/--foreground/--surface/--surface-muted/--border-soft/--accent и действующую .dark. Новые роли вводятся только при подтверждённом отсутствии аналога, без второй темы и генератора токенов. Палитра графика не становится цветом мелкого текста автоматически.

Измерять реальные сочетания текст/фон, статус/подложка, focus/соседняя поверхность и выбранные/disabled состояния. Сохранять существенные единицы и причины при узкой ширине и увеличении текста. Склонения проверять на0/1/2/5/11/21; не собирать предложения несовместимыми фрагментами.
