# Окна времени в игровых целях (минуты игры)

Актуально на **04.10.2026**.

Цель «минуты игры» (`taskType: PLAY_TIME`, `aggregation: duration`,
события `PLAY_HOUR`/`SESSION_STOP`) может ограничиваться днями недели
(`metric.weekdays`) и часами (`metric.hours`, например `08:00-17:00`). Как
сессия соотносится с этим окном, задаёт `metric.windowMatch`.

| `windowMatch`            | Что засчитывается                                                                                             |
| ------------------------ | ------------------------------------------------------------------------------------------------------------- |
| `SESSION_END` (по умолчанию) | вся длительность сессии, если момент её **окончания** попал в окно                                         |
| `OVERLAP`                | только минуты сессии, лежащие **внутри** окна; начало и конец могут быть вне его; полночь делит сессию по дням |

- Сессия — интервал `[окончание − длительность, окончание]`. И «живые»
  события `PLAY_HOUR`/`SESSION_STOP`, и факты журнала
  `*_PLAY_TIME_ACCUMULATED` несут момент окончания и длительность, поэтому
  оба пути движка (`guest-game-progress.ts` и резервный
  `guest-game-rule-evaluator.ts`) считают одинаково через
  `guest-game-session-window.ts`.
- `minSessionMinutes` в режиме `OVERLAP` проверяется по минутам внутри окна:
  с `minSessionMinutes = 60` засчитывается только сессия, у которой внутри
  окна не меньше 60 минут; минуты разных сессий не складываются.
- Часы и дни — по часовому поясу клуба; `23:59` закрывает сутки, окно
  `22:00-02:00` переходит через полночь.
- В админке режим задаётся полем «Как учитывать окно времени» в условии шага
  сезона («Сессия заканчивается в окне» / «Минуты сессии внутри окна»).
  API сохраняет поле при любом сохранении сезона.

## Где используется

- GAMEPASS vol.1, шаг 4 «GOOD MORNING, VIETNAM»: будни `08:00-17:00`,
  `minSessionMinutes = 60`, `windowMatch = OVERLAP` (решение владельца
  04.10.2026; до этого — `SESSION_END`, «сессия должна закончиться с 08:00 до
  17:00»). Текст для гостя: «В будни сыграйте одну сессию, в которой не
  меньше 60 минут приходятся на время с 08:00 до 17:00».
- Остальные шаги с окнами (LET'S GO, WEEKEND, K.O., FINAL) остаются в
  `SESSION_END`: перевод FINAL (`09:00-21:00`, сумма минут) в `OVERLAP`
  уменьшил бы засчитанное время у части гостей.
