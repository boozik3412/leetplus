# 0001. Привязка сессии не изменяет время факта

## Контекст

Дата решения: 14.09.2026. D01: выводимая привязка сессии к Store может дать timezone для существующего разбора дат.

## Решение

Привязка сессии к клубу отделяется от разбора даты: origin и уже сохранённые timestamps остаются без изменений.

## Почему

Отклоняется применение inferred Store для timezone существующего parser: оно способно сдвинуть время факта. Исправление timezone не входит в это решение по дашборду.

## Последствия

Покрытие привязки остаётся наблюдаемым, включая unknown при недостатке доказательств. Сессия связывается только с доказанным tenant/provider/domain/club; это ограничение не даёт переопределять историческое время.
