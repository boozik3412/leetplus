# 0005. Синхронизация остатков не продвигает курсор продаж

## Контекст

Дата решения: 14.09.2026. D06: inventory-only режим способен продвинуть cursor, используемый catchUp для продаж.

## Решение

Курсор продаж продвигается только после полностью успешных режимов, которые загружают продажи; inventory и catalog синхронизации его не изменяют.

## Почему

Отклоняется использование успеха INVENTORY/CATALOG как доказательства пройденного sales catchUp: это может пропустить недогруженные продажи. Общая последняя активность также не доказывает полноту каждого раздела.

## Последствия

Свежесть остатков, каталога и продаж оценивается по собственным фактам и scope. Успех одного раздела не делает другой раздел свежим и не скрывает неполноту sales данных.
