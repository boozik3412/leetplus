# 0006. Передавать полный scope выбранных клубов

## Контекст

Дата решения: 14.09.2026. D08: прежний путь главного виджета при нескольких клубах заменял выбор всей сетью.

## Решение

Совместимый API и связанный UI-путь передают полный массив выбранных клубов в загрузку и переход к целевому отчёту риска.

## Почему

Отклоняется scalar storeId и снятие фильтра при множественном выборе: они меняют смысл запроса и показывают данные всей сети вместо выбранного scope.

## Последствия

Карточка и открываемый ею отчёт используют один и тот же полный query scope вместе с остальными переносимыми фильтрами. Другие блоки главного дашборда не меняются этим ограниченным решением.
