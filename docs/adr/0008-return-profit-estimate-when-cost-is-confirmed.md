# 0008. Возвращать оценку прибыли при подтверждённой себестоимости

## Контекст

Дата решения: 14.09.2026. D10: общий адаптер старых финансовых полей OOS возвращает null даже для строки с известной себестоимостью.

## Решение

Общий engine возвращает дневную оценку валовой прибыли при подтверждённой unit cost и сохраняет cost basis, coverage и asOf рядом с этой оценкой.

## Почему

Отклоняется безусловный null для всех строк OOS: он теряет доступную вычислимую оценку. Продажная оценка не принимается за себестоимость; при действительно отсутствующем подтверждении cost возвращается null с причиной.

## Последствия

Подтверждённая историческая себестоимость оценивается в 21-дневном окне, а current configuration учитывается в границах asOf. Каждая возвращённая оценка остаётся квалифицированной своим basis и coverage, без объявления неполной стоимости точной.
